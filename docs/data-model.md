# Datamodell

En normaliserad arkivpost har ett internt ID, källsystem, källans ID, titel,
beskrivning, käll-URL, eventuell tidsangivelse, eventuell geografi samt tidpunkt
för hämtning. Källans rådata bevaras som JSON för spårbarhet.

Historisk precision ska inte överdrivas. Framtida geografiska modeller ska kunna
representera osäkra koordinater, datumintervall och kvalitetsgrad.
